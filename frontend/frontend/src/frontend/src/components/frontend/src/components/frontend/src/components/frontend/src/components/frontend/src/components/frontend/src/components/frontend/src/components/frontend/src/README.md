# AI Resume Maker

A full-stack app for creating professional resumes/CVs using AI.

## Setup
1. Clone the repo.
2. Install dependencies: `npm install` in both `backend/` and `frontend/`.
3. Set up `.env` files.
4. Run backend: `cd backend && npm start`.
5. Run frontend: `cd frontend && npm start`.

## Features
- Login with Firebase.
- Select resume type, profession, answer questions, upload photo.
- AI-generated resumes via Google Gemini.
